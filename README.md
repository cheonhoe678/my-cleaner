# 유저 접속량 정리기

## 쓰기 전에
1. **파일은 브라우저를 떠나지 않습니다.** 넣은 엑셀은 이 브라우저 안에서만 읽고 계산합니다. F12 → Network 를 열고 정리해 보면, 새로 생기는 요청은 처방 파일(`rules/유저접속량.json`) 하나뿐입니다. 요청 주소에 파일 이름이 들어가니, 이름 자체가 정보인 파일이라면 이름을 바꿔 넣으세요.
2. **이 정리기가 못 하는 것.** 지어낸 데이터로 정답과 대조했을 때 «놓쳤다»는 0줄이었습니다. 하지만 모르는 값을 지어내지 않으려고 고치지 않고 표시만 한 33줄 — 빈칸 10 · 튀는 값 6 · 연도 두 자리 날짜와 초 없는 시간 10 · 접속시간 모순 7 — 은 사람이 확인해야 합니다.
3. **처방은 `rules/` 의 파일을 고칩니다.** 코드(`clean.js`)에는 처방이 없습니다. 처방마다 «왜»가 적혀 있으니 바꿀 때 이유도 함께 고치세요.

## 쓰는 법
1. 사이트를 엽니다. (내 컴퓨터에서는 이 폴더에서 `python -m http.server 8000` 후 `http://localhost:8000`)
2. `data/유저접속량.xlsx` 같은 엑셀을 끌어다 놓습니다. 같은 이름의 처방 파일을 `rules/` 에서 찾습니다.
3. «규칙대로 정리»를 누르고, 정리본과 바꾼 기록을 내려받습니다.

## 들어 있는 것
- `index.html` · `style.css` · `app.js` · `clean.js` — 화면과 계산
- `lib/` — 엑셀을 읽는 SheetJS 0.20.3 (Apache-2.0, 라이선스 포함)
- `rules/유저접속량.json` — 처방과 이유 (정한 사람: 김천회)
- `data/유저접속량.xlsx` — 지어낸 연습용 엑셀. 실제 회사 자료가 아닙니다
